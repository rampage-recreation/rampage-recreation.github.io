Build46：Old West 八栋建筑挑战及单栋练习，支持键盘和手机屏幕按钮。

操作

方向键/WASD移动，靠墙↑攀爬，J抓取/拆楼，K拳击，楼顶↓＋J砸楼，Space跳跃，POWER蓄满按L，P暂停，R重开。手机可同时按住方向与动作按钮。

声音默认关，点击声音按钮启用；可使用“试音 / 重试”重建声音通道。音效为合成音效，没有原版背景音乐。
