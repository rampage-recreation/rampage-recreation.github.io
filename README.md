二十个时代代表关 / George，支持电脑键盘与手机屏幕按钮。Build58 修复了地面和飞行敌人在画面左右提前消失的问题；该专项于2026-10-27用户复测通过，整体二十关手机验收由用户暂缓。

可选择时代或连续闯关，进度从当前时代起点保存到当前浏览器与网址。方向键/WASD移动，↑攀爬，J抓取/拆楼，K拳击，Space跳跃，满POWER按L，P暂停，R重开。声音可由按钮启用。

## 来源与范围

对 PS1《Rampage Through Time》（USA，SLUS-01065）的研究复刻，包含原作提取图像和部分逆向移植逻辑。原作名称及内容的权利归相应权利人；公开仓库不构成第三方内容授权，也未为原作素材添加开源许可。合成音效，无原音乐；不包含ROM、EXE、BIOS、完整RAM/VRAM或光盘，运行无需这些文件。

二十个时代代表关，不是全部60城市、全角色或完整原引擎；少数原动画、Cleito独立游泳等未恢复。存档与恢复后的短暂保护等为明确的网页适配。详见[来源与边界](provenance.json)、[冻结时修复报告](REPORT58.md)和[最新验收状态](acceptance.json)。旧Build50报告和截图是历史记录，以此版本说明为准。

本地运行：`python3 -m http.server 8777` 后打开 http://localhost:8777/ 。GitHub Pages 沿用 main 分支根目录。
