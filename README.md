二十个时代代表关，不是全部60城市、全角色或完整原引擎。Shiraz/Divax少数panic原图与时序缺失，使用明确的当前关跑步帧视觉替代；Cleito当前原版资料未证明有独立游泳机制。存档、部分碰撞/恢复保护和资源/绘制策略为网页适配。详见[来源](provenance.json)、[61性能报告](REPORT61.md)、[60下爬报告](REPORT60.md)、[59视觉报告](REPORT59.md)。旧50/58文件为历史，当前以61说明为准。
